Política de Privacidade

RCD YouTube Dashboard

Atualizada em novembro de 2026.

1. Sobre o aplicativo

O RCD YouTube Dashboard é uma ferramenta de uso privado destinada ao acompanhamento estatístico do canal Reflexões Católicas Diárias no YouTube.

2. Dados acessados

O aplicativo utiliza os Serviços de API do YouTube, incluindo YouTube Data API, YouTube Analytics API e YouTube Reporting API.

São consultados dados como títulos e identificadores dos vídeos, datas de publicação, visualizações, tempo de exibição, impressões, taxas de cliques, origens de tráfego e estatísticas agregadas de desempenho.

O acesso aos dados autorizados ocorre mediante autorização OAuth do Google. O aplicativo também utiliza tokens de autorização para manter a conexão.

3. Finalidade

Os dados são utilizados exclusivamente para análise de desempenho, planejamento editorial e acompanhamento dos resultados do canal.

4. Armazenamento e compartilhamento

Os dados consultados são processados por serviços Google, incluindo Google Apps Script, e armazenados em planilhas Google Sheets. Podem ser apresentados em painéis internos do Looker Studio.

O aplicativo não comercializa os dados obtidos pelas APIs do YouTube e não disponibiliza acesso público aos dados autorizados do canal.

5. Revogação do acesso

A autorização concedida ao aplicativo pode ser revogada a qualquer momento nas configurações de segurança da Conta Google:

Gerenciar permissões da Conta Google

Após a revogação, o aplicativo deixa de ter autorização para novas consultas. Dados autorizados anteriormente armazenados devem ser excluídos conforme as políticas aplicáveis do YouTube, inclusive o prazo máximo de sete dias previsto para exclusão após revogação.

6. Segurança

O acesso é restrito às contas autorizadas. O aplicativo utiliza os mecanismos de autenticação OAuth do Google e não solicita o armazenamento de senhas do YouTube.
